核心能力

一套思路，两种编辑器

从单行代码到整个项目，按需选择检查与转换方式。

01

边写边检查

字符串字面量中的中文会被高亮标记，悬停即可查看问题说明。

02

四种地区用法

简体、台湾、香港与通用繁体任选检查与转换目标，默认跟随 IDE 显示语言。

03

精细排除

按语言排除 print、console.log、标签或键名，减少误报。

04

自定义词典

用 OpenCC 格式词条覆盖内置转换，可放入仓库供团队共享。

05

全项目扫描

一次扫描整个项目，按文件查看结果，勾选后批量接受，撤销一步还原。

06

按需自动检查

可开启打开项目后后台检查，默认关闭，不会自动改动文件。

工作流

三步完成本地化校正

不改变你的编码习惯，在需要的时候给出结果。

1

编写或打开项目

像平时一样写代码；插件会在字符串中标记中文。

2

选择目标用法

在设置里指定要检查的地区与目标地区。

3

应用快速修复

单条修复或全项目批量接受，一次撤销即可回滚。

两个产品有什么区别？

功能定位相同，分别面向 VS Code 与 IntelliJ 平台 IDE；具体支持语言和操作路径略有差异。

会自动修改我的文件吗？

不会。快速修复由你主动触发；全项目扫描只生成结果列表，接受后才会修改，且可一次撤销。

自定义词典有数量限制吗？

IntelliJ 插件最多 20,000 条；VS Code 扩展按目标字形分文件存放，可通过管理界面导入导出。

可以把词典放在仓库里共享吗？

可以。VS Code 设置 customDictionaryDirectory 指向仓库内目录；IntelliJ 支持按项目或全局共享设置。

支持哪些中文地区？

简体中文、中文（台湾）、中文（香港）与通用繁体，检查和转换目标可分别设置。
